# 总包计算器 (Package Calculator)

美团（3690.HK）员工总包收入计算器。输入月薪、年终奖、股票激励明细，一键计算当年和下一年的总包（授予价值口径）。

## ✨ 功能

- **收入账本**：输入月薪 + 年终奖月数，实时算出现金部分
- **股票激励**：不建 OCR，引导用户复制 Prompt 去豆包整理授予明细，粘贴返回的 JSON 即可
- **多条授予**：支持历史多年授予记录叠加
- **授予价值口径**：股票价值 = 授予日收盘价 × 授予日汇率 × 授予股数（非归属日股价）
- **非交易日处理**：股价/汇率各自往前找最近交易日（港股与人行日历不同步）
- **今年/明年切换**：tab 切换查看两个年度总包

## 🚀 使用

纯静态前端，无后端。直接打开 `src/index.html` 或部署到任何静态托管（Cloudflare Pages / Vercel）。

## 🔧 数据更新

数据源：
- **股价**：腾讯财经港股K线接口（3690.HK，1300交易日）
- **汇率**：中国人民银行人民币兑港元中间价（2005至今）

更新命令：
```bash
# 1. 重新抓取数据
python3 scripts/fetch_data.py
# 2. 重新构建前端数据文件
python3 scripts/build_js_data.py
```

## 📐 计算口径

```
单笔授予价值 = 授予股数 × 授予日收盘价 × 授予日汇率
当年总包 = 月薪×(12+年终奖月数) + Σ(当年归属比例 × 授予价值)
```

- 非交易日：股价/汇率各自往前找最近交易日
- 归属比例 = 当年归属股数 / 授予股数
