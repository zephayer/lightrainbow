# 总包计算器 (Package Calculator)

美团（3690.HK）员工总包收入计算器。输入月薪、年终奖、股票激励明细，一键计算当年和下一年的总包（授予价值口径）。

## ✨ 功能

- **收入账本**：输入月薪 + 年终奖月数，实时算出现金部分
- **股票激励**：不建 OCR，引导用户复制 Prompt 去豆包整理授予明细，粘贴返回的 JSON 即可
- **多条授予**：支持历史多年授予记录叠加
- **授予价值口径**：股票价值 = 授予日**上月均价 × 上月最后一天汇率** × 授予股数（非授予日单日价）
- **非交易日处理**：股价/汇率各自往前找最近交易日（港股与人行日历不同步）
- **今年/明年切换**：tab 切换查看两个年度总包

## 🚀 使用

纯静态前端，无后端。直接打开 `src/index.html` 或部署到任何静态托管（Cloudflare Pages / Vercel）。

## 🔧 数据更新

数据源：
- **股价**：腾讯财经港股K线接口（3690.HK，1300交易日）
- **汇率**：中国人民银行人民币兑港元中间价（2005至今）

### 更新时机

> 口径说明：本计算器按「**授予日**」计价（授予日**上月均价 × 上月最后一天汇率**）。**历史授予**一经授予其计价数据便固定不变；只有**未来新增授予**才需要最新的数据。美团的股票授予主要集中在 **10 月和次年 4 月**，因此按以下策略更新——4/1 更新后 4 月授予可用 3 月均价，10/1 更新后 10 月授予可用 9 月均价，时机正好对齐：

| 场景 | 触发方式 | 说明 |
|------|---------|------|
| 每年 4/1、10/1 | ✅ 自动（GitHub Actions 定时） | 授予季自动抓取最新股价/汇率→重新构建→部署 |
| 新授予临时发生 | ✅ 手动（Actions 手动触发） | 在 Actions 页面 Run workflow，默认勾选「更新数据」 |
| 仅改代码不更新数据 | ✅ 手动/代码 push | 提交代码即自动部署，不重抓数据 |

### 自动更新（GitHub Actions）

git push 之后无需任何操作，`deploy.yml` 已配置：
- **定时**：每年 `4/1`、`10/1` 08:00（Asia/Shanghai）自动更新并部署
- **手动**：Actions → Deploy to GitHub Pages → Run workflow（勾选 `update_data` 更新数据）
- **代码提交**：仅部署，不重抓数据（避免每次改代码都产生数据 commit）

### 本地手动更新

```bash
# 1. 重新抓取数据
python3 scripts/fetch_data.py
# 2. 重新构建前端数据文件
python3 scripts/build_js_data.py
# 3. 提交并推送（触发自动部署）
git add data/ src/data/
git commit -m "更新股价/汇率数据"
git push
```

## 📐 计算口径

```
单笔授予价值 = 授予股数 × 授予日上月平均收盘价 × 授予日上月最后一天汇率
当年总包 = 月薪×(12+年终奖月数) + Σ(当年归属比例 × 授予价值)
```

- **上月均价**：授予日前一个自然月所有港股交易日的收盘价平均值（如授予日 2024-06-15 → 取 2024年5月均价）
- **上月汇率**：授予日前一个自然月最后一天的人行港币中间价
- 非交易日：股价/汇率各自往前找最近交易日
- 归属比例 = 当年归属股数 / 授予股数
